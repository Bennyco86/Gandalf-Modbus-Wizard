# Gandalf Modbus Wizard Support

Gandalf Modbus Wizard support is provided through the public GitHub issue tracker:

`https://github.com/Bennyco86/Gandalf-Modbus-Wizard/issues`

You can also contact the developer at `nzbennycohen@gmail.com`.

## Before Requesting Support

Check the README and existing issues first. When opening a new issue, include:

- Gandalf Modbus Wizard version
- Windows, Linux, or macOS version
- Modbus TCP, Modbus RTU, or Simulation workflow
- Device model and protocol settings, where safe to disclose
- Exact error message and reproducible steps
- Whether the issue also occurs after restarting the application

Do not post passwords, API keys, private customer information, full private network
details, or confidential register maps in a public issue.

## Microsoft Store Edition

The Microsoft Store purchase provides Store installation and updates while
supporting continued development. The core project also remains available from the
public GitHub repository under its MIT licence.

Microsoft handles Store purchases and refunds under its applicable terms. The
developer cannot directly process a Microsoft Store payment refund.

## Scope

Support covers installation problems, application defects, packaging problems,
and documented Gandalf features. It does not include responsibility for configuring
third-party PLCs, changing production control systems, or guaranteeing compatibility
with every vendor-specific Modbus implementation.
