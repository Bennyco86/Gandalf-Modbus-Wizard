# Gandalf Modbus Wizard Privacy Policy

Last updated: 4 August 2026

Gandalf Modbus Wizard is a desktop utility developed by Benny Cohen for scanning,
diagnosing, trending, and simulating Modbus devices.

## Information Collected

Gandalf Modbus Wizard does not collect telemetry, analytics, advertising data,
account information, passwords, or payment information. The application does not
send usage information to the developer.

Microsoft may process account, purchase, installation, diagnostic, and Store usage
information when the application is obtained through Microsoft Store. That
processing is governed by Microsoft's privacy terms and is separate from Gandalf
Modbus Wizard.

## Information Stored Locally

The application may store the following information on the user's device:

- Application preferences and the most recently used connection settings
- Diagnostic log files generated while using serial auto-detection
- Register data, trends, or reports exported to a file selected by the user

On Windows, mutable application data is stored under:

`%LOCALAPPDATA%\GandalfModbusWizard`

This information remains on the user's device unless the user chooses to share or
remove it.

## Device and Network Communication

Gandalf communicates with Modbus TCP endpoints, local test servers, and serial
ports selected by the user. Network Diagnostics runs only after the user starts
it. The application does not route this communication through a developer-operated
service.

The application can open Windows diagnostic utilities and external web links at
the user's request. Those utilities and websites operate under their own privacy
terms.

## Data Sharing

The developer does not receive or sell information from Gandalf Modbus Wizard.
The application contains no advertising network or third-party analytics SDK.

## Security

Users are responsible for ensuring they have permission to communicate with the
devices and networks they select. Avoid including passwords, customer information,
or other sensitive data in exported files or public support reports.

## Children

Gandalf Modbus Wizard is an engineering utility and is not directed at children.
It does not knowingly collect personal information from children.

## Changes

This policy may be updated when application behavior or distribution requirements
change. The current version will be published with the project documentation.
